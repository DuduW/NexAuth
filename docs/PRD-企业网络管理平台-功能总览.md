## 1. 产品定位

面向企业网络运维的一体化管理平台，部署于 `192.168.110.106`（Ubuntu 22.04），统一管理：

- **网络准入与认证**：802.1X EAP-TLS 证书认证、MAC 旁路免认证、Portal 认证、RADIUS 记账
- **VPN 接入**：WireGuard 隧道、用户授权、连接/访问/流量日志
- **数字资产**：网段 / IP 地址台账 / 公网资产 / NAT 映射
- **设备资产**：华为交换机（VRP）纳管、配置备份、在线巡检、定时任务
- **系统运维**：服务器状态、登录安全管理

**职责边界**：本平台只管 106 体系（FreeRADIUS 单节点 192.168.110.106）；AC6003 上 QLink 体系（QLinkRADIUS/QLink-Portal 等模板）完全独立，不在本平台管理范围。

## 2. 用户角色

| 角色 | 说明 | 权限来源 |
|------|------|----------|
| 网络管理员 | 全功能操作 | radcheck 用户 + radusergroup `admin` 组 + TOTP 动态码 |
| VPN 用户 | 仅 NetAgent/WireGuard 客户端拨入 | radcheck 用户 + vpn_peers 授权 |
| 普通上网用户 | 终端认证（无后台） | radcheck / radmacbypass / 证书 |

登录安全：同 IP+账号连续 5 次失败锁定 15 分钟（进程内计数，服务重启清零）。

## 3. 功能模块明细

### 3.1 准入与认证中心（/nac/*，四页面）

| 页面 | 子功能 | 要点 |
|------|--------|------|
| **运行监控** | 在线会话 / 认证日志 / 记账查询 | 在线判定 = 会话未结束 **且** 最近 5 分钟有记账活动；快捷排障条一键带参跳转 |
| **准入策略** | MAC 免认证 / 用户 Profile / RADIUS 参数 | MAC 旁路 6 个月有效期自动注册；Profile 绑定 VLAN/QoS/ACL 随 Accept 下发；华为 VSA 限速参数管理 |
| **服务配置** | NAS / 字典 / 用户回包 / 组控制 / Portal / 证书 | NAS Secret 打码+点击审计；Portal 服务启停+参数编辑；EAP-TLS 证书签发/吊销（CA: qcc-radius-ca-2026） |
| **链路拓扑** | 全链路 SVG 拓扑 | 终端→NAS（AC6003/S57）→FreeRADIUS(106)→MySQL/Portal；端口徽章 1812 认证/1813 记账/3799 CoA；节点数字实时取 overview |

### 3.2 用户与认证（/users /groups /totp）

| 功能 | 说明 |
|------|------|
| 用户管理 | 增删改查；行内编辑改组（admin 等）；改密；业务组与 Profile 双维度 |
| 用户组 | radusergroup + radgroupcheck/radgroupreply 参数组管理 |
| TOTP 动态码 | Google Authenticator 绑定（QR 本地生成）、启用/禁用/重置；后台登录强制 |

### 3.3 VPN 管理（/vpn*，五页面）

| 页面 | 功能 |
|------|------|
| 节点管理 | WireGuard 服务端配置（UDP 8001 / 10.99.0.0/24）、peer 管理、conf 下载 |
| 权限管理 | 用户 ↔ 节点授权（vpn_peers），IDC 路由 172.18.0.0/24 按需下发 |
| 连接/访问/流量日志 | NetAgent 上报 + **服务端采集器**（vpn_probe 30s 扫 wg show，官方 WireGuard 客户端同等纳管） |

### 3.4 数字资产管理（/ip-*，三页面）

网段管理（IPv4/IPv6 双栈）、地址台账（含审计）、公网资产与 NAT 映射。

### 3.5 设备资产管理（/sw*，四页面）

| 页面 | 功能 |
|------|------|
| 设备清单 | 华为交换机 CRUD、SSH 凭据（AES-256-GCM 加密存储）、连接测试 |
| 备份管理 | 版本化配置备份、diff 对比、下载归档、删除 |
| 在线分析 | 全量巡检 + **单台巡检**（CPU/内存/温度/告警/接口）、24h 趋势、离线防抖（连续 3 次） |
| 定时任务 | cron 表达式定时备份、手动运行、运行历史 |

### 3.6 系统管理（/server /settings）

服务器状态（服务/端口/DB/趋势）、主题与语言设置。

## 5. 核心数据口径

| 指标 | 口径 |
|------|------|
| 在线会话 | radacct：acctstoptime IS NULL **且** acctupdatetime ≥ NOW()-5min |
| 认证成功/失败 | radpostauth.reply LIKE 'Access-Accept%' / 否则 |
| 记账数据链 | AC →(UDP 1813)→ FreeRADIUS detail 文件 → detail_sync（每分钟）→ radacct |
| VPN 会话 | vpn_probe 30s 扫描 wg0 握手；180s 无握手自动关会话 |
| 巡检离线 | 连续 3 次采集失败才标记离线（防抖） |

## 6. 运行架构（产品视角）

```
终端(无线 test011/test022 · 有线 S57 · MAC 旁路设备)
   │ 802.1X / Portal / 免认证
   ▼
NAS 设备（AC6003 192.168.30.15 · S57 交换机）
   │ UDP 1812 认证 / 1813 记账 / 3799 CoA
   ▼
FreeRADIUS 3.0（106）── MySQL 8.0（radius 库 70 表）
   ▲                        ▲
   │ PAP                    │ SQL
Portal 服务(:8080/:50100)   radius-admin(FastAPI :8000)
                                ▲
                                │ HTTP API
                        admin-spa 前端（nginx /admin-spa/）
```

辅助进程：detail_sync（记账入库）、vpn_probe（VPN 会话采集）、vpn_visit_collector、zt_*（零信任已下线，任务保留）。
