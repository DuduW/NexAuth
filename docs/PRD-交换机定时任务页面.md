## 1. 页面定位

交换机定时备份任务的管理中枢：创建/编辑按 cron 周期执行的备份任务，查看下次执行时间与历史执行记录，支持手动立即执行与启停。调度与 radius-admin 服务同进程（APScheduler），任务变更即时生效、无需重启。

## 3. 任务列表字段

| 列 | 来源/渲染 | 说明 |
|---|---|---|
| 状态 | enabled → badge-success「启用」/ badge-default「停用」 | |
| 任务名称 | name 加粗；remark 第二行 .mut | 唯一名，重复创建后端 409 |

## 4. 交互流程

### 4.1 新建任务（formDialog 表单，7 字段）
1. 任务名称（必填，≤64 字符）
2. 备份设备（**checks 多选**，选项=设备台账全部设备；空选提交被「必填项」拦截）
3. 执行周期（默认 `0 2 * * *`，hint 提示：每天02:00 / 每周日02:00=`0 2 * * 0` / 每月1日=`0 2 1 * *`）
4. 每设备保留份数（默认 30，校验 1–1000 数字）
5. 每日末份永久保留（select 关闭/启用）
6. 备注（选填）
- 提交 → `POST /sw/tasks`；cron 非法由后端拒绝（ValueError → 422/500 提示）；成功 toast「任务已创建并启用调度」并刷新。

### 4.2 立即执行
- 点击后 toastInfo「执行中（逐台串行，请稍候）」，等待完成（任务内设备串行 + 1s 间隔）。
- 结果三态 toast：✅ 全部成功 / 🟡 部分成功（ok/fail） / 🔴 失败。
- 与定时触发互斥：执行中再次触发返回 409「任务正在执行中」。
- 成功后刷新列表；若该任务执行记录面板已展开则同步刷新。

### 4.3 执行记录展开
- 「记录」按钮切换展开/收起；`GET /sw/tasks/{id}/runs` 最近 50 条。
- 每行：开始时间 / 触发方式（手动 badge-blue / 定时）/ 结果 badge / 成功·失败·跳过 计数 / 明细（每设备一行：✅成功·v版本号 ⏭跳过 ❌失败·原因，nowrap）。

### 4.4 启停 / 删除
- 启停 → `PUT` enabled，调度即时移除/装载，toast 说明「调度已移除/已装载」。
- 删除 → ConfirmModal 二次确认（说明：仅删任务与调度，备份版本与执行记录保留）→ `DELETE /sw/tasks/{id}`；执行中任务 409 拒删。

## 5. 接口映射

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/sw/tasks | 列表（含 device_names、next_run_at） |
| POST | /api/sw/tasks | 创建（重名 409；设备不存在 422） |
| PUT | /api/sw/tasks/{id} | 编辑/启停（调度热更新） |
| DELETE | /api/sw/tasks/{id} | 删除（执行中 409） |
| POST | /api/sw/tasks/{id}/run | 立即执行（执行中 409） |
| GET | /api/sw/tasks/{id}/runs | 执行记录（limit≤200） |

## 6. 状态与异常态

| 场景 | 表现 |
|---|---|
| 空任务 | empty 引导「点击右上角新建任务」 |
| 列表加载失败 | toastError |
| 任务名重复 | 409 toast「任务名已存在」 |
| cron 非法 | 后端拒绝，toast 显示原因 |
| 设备执行失败 | 单台失败不中断任务，任务状态=partial；明细内 ❌ 原因 |
| 设备已停用/不存在 | 计入 skip，明细 ⏭ |

## 7. 视觉规范（对齐 admin-spa / 准入页面惯例）

- 背景 #f5f5f7 + 白卡片 + 14~16px 圆角；主色 #1450C8。
- 正文默认 13px，辅助信息 12px（.mut / .badge 同全站），无 11px。
- badge 色系：成功 #188a5b、部分成功 #b45e13、失败 #c23c34、手动 #1450C8、默认灰。
- 时间格式 `YYYY-MM-DD HH:mm`（substring(0,16)，T 替换为空格）。
